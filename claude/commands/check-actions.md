description: Check GitHub Actions status for current branch and create action plan
---

Switch into plan mode if not there already.

Check the status of GitHub Actions for the current branch PR using `gh`, then:

1. Identify any failing checks and analyze error logs
2. Determine the root cause of failures
3. Create a detailed action plan with:
   - Summary of failing/passing checks
   - Root cause analysis
   - Step-by-step fix instructions
   - Files to modify
   - Testing strategy
